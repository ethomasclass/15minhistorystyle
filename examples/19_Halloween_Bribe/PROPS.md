# AI props (cut-out objects for the desk)

Photoreal period objects generated on white with `gemini-3-pro-image` (2K, 1:1), cut out with `python3 tools/prop_cut.py [names]`.
Prompts: `public/img/props/src/<name>.txt` (each ends with the same studio-catalog style paragraph). Sources: `src/<name>.jpg`;
cut-outs: `public/img/props/<name>.webp`. Rejected takes in `rejects/`.

On screen they are props, not artifacts: B&W on the dark desk, one coral subject per scene, **no source tag and never "AI" on
screen** (the channel's rule); keep this file as the record. Never present one as a specific real object ("this is the tear-gas
grenade used in Bismarck"); say "tear gas", not "this grenade".
