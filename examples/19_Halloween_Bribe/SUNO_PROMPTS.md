# Suno prompts: Trick-or-Treating Was a Bribe (Halloween)

Five new cues, `hb_` prefix. Copy each **Style** box and its **Lyrics** tags box into Suno; everything else is labels.
The rest of the score reuses the library (see the chapter map at the bottom).

**Why these tempos:** the narration runs about 165 words a minute, so mid tempos with space sit under it. I cut and hand over on a
musical phrase, so the BPM only sets the feel.

## Settings (same for every cue)

- **Custom** mode.
- **Style:** paste the cue's box.
- **Lyrics:** turn **Instrumental OFF** and paste only the structure-tags box (all in [brackets], starting with [Instrumental], so
  there's nothing to sing). If a take hums or sings anyway, throw it out, or switch Instrumental on and use the Style box alone.
- **Exclude styles:** paste this every time:

```
vocals, choir, lyrics, humming, spoken word, EDM, trap, pop, rock, synth lead, dubstep, rap, cinematic trailer, epic, new age, comedic, cartoon
```

- Make **2–4 takes**; keep the one whose **first 30–40 seconds** already sound right.
- **Length:** at least the minimum listed. Longer is fine (I trim and fade). Too short? **Extend** from the last good section.
- **Download as MP3** and name it exactly as shown (e.g. `hb_black_halloween.mp3`). Send them back and I'll level, cut and place them.
