# Examples

The working documents from each video, copied as they were when the video was finished. Use them as models: when Claude writes a
SCRIPT.md, a prompts file, a MUSIC.md or YouTube text for a new video, it should look like these.

| Video | Documents |
|---|---|
| [01 Fix Everything](01_Fix_Everything/) | design style guide (where the look was first written down), style test, Gemini prompts, YouTube text, handoff, **Shorts notes** |
| [02 The War Nobody Won](02_War_Nobody_Won/) | script v2, accuracy changes, handoff (the toy-theater look) |
| [03 Bierce](03_Bierce/) | script, image and Suno music prompts, YouTube text |
| [04 King Andrew](04_King_Andrew/) | script, Gemini prompts, music plan, YouTube text, handoff, **Shorts notes** |
| [05 Grip Tighter](05_Grip_Tighter/) | script, **fact-check with verdicts**, image plan, music plan with Suno prompts, YouTube text, viewing guide |
| [06 Good Luck (Ouija)](06_Good_Luck_Ouija/) | script, production plan, prompts (paintings, music, SFX), music plan, YouTube text, handoff |
| [Axeman](Axeman/) | script, image plan, music plan and public-domain music notes, YouTube text, handoff (the project itself moved to its own repo, `ethomasclass/axeman`) |
| [07 Say It Ain't So (Black Sox)](07_Say_It_Aint_So/) | script with fact-check flags (and a readable PDF), image index with credits, music plan, unused Flow "tobacco card" prompts, YouTube text, **Shorts text**, handoff |
| [08 The Exact Spot](08_Exact_Spot/) | script, outline, visual plan, **Flow wood-engraving master prompt**, music plan with Suno prompts, YouTube text, the lesson card, **student viewing guide + teacher key**, handoff |

Paths inside these files point into each video's own repo, not into this one (07's point into `projects/Black_Sox/` on the `black-sox-video` branch of this repo; 08's into `projects/Mexican_American_War/` on `claude/relaxed-lamport-62biq7`).

**Later videos** (*When Europe Ate Mummies*, *The Balloon War*, *Log Cabin*, the Civil War videos *In Their Own Words*, *Forever Free*
and *Except*, the *Reconstruction* series and the *American West* series) keep their working documents in their own folders under
[`../projects/`](../projects/), which are all on the main line of this repo now, so they aren't copied here.

The first standalone Shorts skill (Oct 9) is kept, inactive, in [`../techniques/archive/15-minute-history-shorts-skill/`](../techniques/archive/15-minute-history-shorts-skill/)
for its scripts (segment finder, cover frames, anchor check) and `Short.tsx`; the guidance itself now lives in the main skill's
`references/shorts.md`.
