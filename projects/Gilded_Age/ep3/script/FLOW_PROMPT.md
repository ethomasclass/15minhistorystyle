# Google Flow prompts: Episode 3 cut-out props

Same pipeline as Episodes 1 and 2: photographed period objects, cut out, shown in black and white on the desk. Portraits, cartoons and
prints (Keppler's "Looking Backward", "The Only One Barred Out", the Chinese Exclusion Act, Castle Garden and Ellis Island photos) come
from the archive, not from Flow. The script is not written yet, so the beats below are the planned ones; a prop that ends up
unused simply isn't placed.

**How to run them**
- **One image per prop.** Copy each block into Flow as it is, and keep the single best take of each (one file per id).
- Square (1:1) if Flow offers it; landscape is fine.
- Reject any take with readable letters or numbers; I add all words and figures in the edit.
- Save as the id + `.png` and send them back in **one zip**.
