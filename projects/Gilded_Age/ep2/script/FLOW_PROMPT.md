# Google Flow prompts: Episode 2 cut-out props

Same pipeline as Episode 1 (`../../ep1/script/FLOW_PROMPT.md`): photographed period objects, cut out, shown in black and
white on the desk. Portraits and prints (the Mora costume photos, the Sun, Spencer, Sumner, Carnegie, the Braddock library) come
from the archive, not from Flow.

**How to run them**
- **One image per prop.** Copy each block into Flow as it is, and keep the single best take of each (one file per id).
- Square (1:1) if Flow offers it; landscape is fine.
- Reject any take with readable letters or numbers; I add all words and figures in the edit.
- Save as the id + `.png` and send them back in **one zip**.
