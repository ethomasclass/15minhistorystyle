# One Hilltop, Three Maps

15 Minute Human Geography, AP Human Geography topic 3.7 (religion), October 2026. Judaism, Christianity and Islam. Length 9:35.

- **Finished video:** `renders/One_Hilltop_Three_Maps_1080p.mp4` (stored with Git LFS) and `renders/One_Hilltop_Three_Maps_720p.mp4`
- **Quick preview and narration:** `review/` (480p preview, narration MP3, student viewing guide PDF, blank world map)
- **Source:** narration in `script/`, voiced audio and word timings in `public/audio/`, images in `public/img/`
  (credits in `public/img/credits.json`), and scenes in `src/ch/`. The world map kit is `src/kit/asia.tsx`.
- **Re-render:** `npm install`, then `tools/render.sh`. No API keys are needed unless you re-voice.
  To re-voice, copy `.env.example` to `.env` and add the keys.
