Every file below is credited in `public/img/credits_chNN.json`. Contact sheets: `review/images_chNN_sheet.jpg` (they skip the builders' `b_` files).
Sources: LOC = Library of Congress (all "no known restrictions" unless noted), NARA = National Archives catalog, Commons = Wikimedia Commons,
IA = Internet Archive scan of a pre-1930 book, AIC = Art Institute of Chicago (CC0).

`mccoy_midnight_storm…` (= `b_mccoy_*`), `ch04/kit_carson_c1863` (= `b_kit_carson`), `ch07/homestake_open_cut_grabill_1888`

Helpers for sources the project tools can't reach (they write credits in the same format): the LOC `/pictures/item` JSON (when
`loc.gov/item` 404s), the NARA catalog, and the template's `phrase_find.py` for the newspaper. Wikimedia throttled hard (429) all
session, so Commons files came down at 1920 px wherever the original is larger.
