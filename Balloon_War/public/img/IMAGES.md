# The Balloon War: archival images

Every file below is recorded in `credits.json`, which holds the full title, author and source page. Licences: **PD** means
a US federal government work (Army/Signal Corps, Navy, Coast Guard, USAF, DoD, DOE/MED, Forest Service, WRA, NPS) or a
work out of copyright; **PD Mark** is the Mikesh 1973 Smithsonian monograph on Internet Archive
(`archive.org/details/japanese-balloon-bombs-1943`, Public Domain Mark 1.0), cropped from page scans (`page nNN` = scan
index). Nothing here is CC BY-SA, NC or ND. Sizes are in pixels. The ★ marks the strongest pick for each beat.

Notes for scenes:
- Several NARA prints are scanned **on their caption card or mount** (some ch02 342-FH and 26-G frames). Crop inside the
  print in the scene (`crop` / `CropCard`).
- The **Anzio rubber tank** photos (ch03) show a British-designed inflatable used by the US Fifth Army in Italy, 1944. They
  are *not* Ghost Army photos. Tag them like `US Army Signal Corps · inflatable rubber tank, Anzio 1944`, and don't
  caption them "Ghost Army".
- **CC BY 2.0** files (ch06 McCullough) need the on-screen credit "Michael McCullough, CC BY 2.0".
- Commons originals were rate-limited (HTTP 429) during this pass, so Commons files are the largest standard thumbnail
  below native size (1280/1920/3840). Native sizes are noted where they're much bigger, in case a re-download is wanted.

## Tool notes (for whoever runs `find_images.py` next)

- `loc` gets: LoC JSON now puts the FSA/OWI public-domain statement in `item.rights`, not `rights_advisory`, so
  `best_loc` refuses public-domain items ("rights say ''"). The Camp Tyson files were fetched with the same test applied
  to `rights`.
- `commons` gets: `upload.wikimedia.org` originals returned HTTP 429 for this session, but `thumb.wikimedia.org` standard
  widths (1280/1920/3840) worked. Also, the licence regex `cc by(?!-nc)` accepts **CC BY-SA**. Every file here was
  checked by hand, and none is BY-SA.
- NARA isn't a `find_images.py` source, but its catalog API (`catalog.archives.gov/proxy/records/search?naId=…`) works
  from here. NARA files above were fetched from their `digitalObjects` and credited with the NAID.
